행위자: 비인증 방문자, 게스트, 회원 A/B, 방장/참가자/관전자, 관리자, 잘못 동작하거나 변조된 클라이언트, 내부 게임 worker/결과 consumer.
경계: 브라우저↔HTTPS proxy↔match 인증/권한↔PostgreSQL; 브라우저↔WSS gateway↔game; 내부 Redis tickets/control/results/registry; 게임↔리플레이 파일; SMTP 외부전달; CI 불신 PR↔러너/네트워크/secrets.
검사 관점: 허용된 성공을 먼저 보장하고, 타인 객체/역할 주장/메시지 변조/중복·재전송·순서 변경/경쟁/부분실패가 그 보장을 깨는지 조사한다.

## 실행 안전
로컬은 새 disposable 프로젝트만. 기존 switch-internal-* 및 swITch-postgres/redis를 사용·변경·삭제하지 않음. 운영 env를 자동 로드하지 않음. CI는 internal network이며 Azure 포함 외부 앱 접근 금지. Azure는 주 에이전트만 직렬 실행, 15분 이하 배치·4명/1방/1작업 상한, 별도 HTTP <=1/s·burst2, 429 대기 및 오류/지연/자원 악화 시 중단. 비밀/PII/토큰/원본 로그를 증거로 보관하지 않음. 소리 muted. 배포/재시작은 별도 승인 필요.
